# ⚡ Rupesh Kumar — Next.js 3D Developer & Engineer Portfolio

A state-of-the-art, interactive 3D WebGL developer portfolio and personal brand website built with **Next.js (App Router)**, **Three.js**, **TypeScript**, and **Vanilla CSS Design Tokens**.

Designed for **Rupesh Kumar** ([@3rupeshkr](https://instagram.com/3rupeshkr) / [er-rupesh7](https://github.com/er-rupesh7)).

---

## 🌟 Key Features

1. **3D WebGL Cyber Cosmos & Hero Scene**:
   - Interactive Three.js wireframe cyber core with orbital satellites, glowing rings, and inertia-based mouse physics.
   - Dynamic 2,000+ starfield particle cosmos reacting to cursor motion and scroll depth.
   - 3D parallax tilt effects with dynamic specular light glare on project and education cards.

2. **Full SEO & Search Optimization Suite**:
   - **`sitemap.ts`**: Dynamic XML Sitemap generator for search engine crawlers.
   - **`robots.ts`**: Crawler directives and sitemap linkage.
   - **`manifest.ts`**: PWA Web App Manifest with icons and standalone display settings.
   - **Schema.org Structured Data (JSON-LD)**: Rich `Person`, `WebSite`, and `EducationalOrganization` schemas.
   - Complete OpenGraph, Twitter summary cards, and canonical links.

3. **Academic Milestones Included**:
   - 🎓 **B.Tech in Computer Science & Engineering** — *Ch. Devi Lal State Institute of Engineering & Technology (CDLSIET), Panniwala Mota, Sirsa, Haryana*
   - 🏫 **Senior Secondary (12th Grade - Non-Medical)** — *Maharaja Agarsain Sr. Sec School, Sirsa, Haryana*
   - 🏫 **Secondary Schooling (10th Grade)** — *Shah Satnam Ji Boys' School, Sirsa, Haryana*

4. **Live In-Browser Admin & Control Panel ("Command Center")**:
   - Press **`Ctrl + E`** (or click **Panel** in the navbar) to open the live visual CMS.
   - Edit personal details, headline, Instagram, GitHub, email, location, and bio on the fly.
   - Add, modify, or delete education milestones, technical skills, and featured projects.
   - Switch color themes (**Cyber Cyan**, **Neon Purple**, **Emerald Matrix**, **Solar Gold**, **Crimson Fire**).
   - **Export Configuration (JSON)** to download a complete backup file.
   - **Import Configuration (JSON)** to restore any saved setup with 1 click.
   - Instant `localStorage` persistence.

5. **Interactive 3D Cyber Terminal**:
   - Built-in CLI shell supporting commands: `help`, `about`, `education`, `skills`, `projects`, `socials`, `theme`, `matrix`, `contact`, `clear`.
   - Tactile Web Audio feedback synthesizer.

## 🚀 Quick Start (Local Development)

```bash
# 1. Navigate to project directory
cd rupesh-3d-portfolio

# 2. Run the Next.js development server
npm run dev

# 3. Open in your browser
# http://localhost:3000
```

## 🌐 Deploy to Vercel (Step-by-Step)

### Option 1: Deploy via GitHub (Recommended)
1. Initialize git and push your repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: 3D Next.js Developer Portfolio for Rupesh Kumar"
   git branch -M main
   git remote add origin https://github.com/er-rupesh7/rupesh-3d-portfolio.git
   git push -u origin main
   ```
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Click **Import Repository** and select `rupesh-3d-portfolio`.
4. Keep the default settings (Framework Preset: **Next.js**).
5. Click **Deploy**. Vercel will automatically build and deploy your site to a live URL (e.g. `https://rupesh-3d-portfolio.vercel.app`).

### Option 2: Deploy with Vercel CLI
```bash
npx vercel
```
